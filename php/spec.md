# PHP for Beginners Slidev deck

- **Framework:** Slidev
- **Aspect ratio:** 16:9
- **Typography:** sans-serif for headings and body copy; monospace is reserved for code examples
- **Visual style:** matched to the JavaScript deck in this repository
- **Content arc:** PHP syntax, variables, data types, operators, control structures, functions, alternative syntax, superglobals, OOP, PDO, and error handling
- **Run locally:** `npm install` then `npm run dev`
- **Build:** `npm run build`
