# JavaScript for Beginners Slidev deck

- **Framework:** Slidev
- **Aspect ratio:** 16:9
- **Typography:** sans-serif for headings and body copy; monospace is reserved for code examples
- **Content arc:** JavaScript purpose, loading a script, data types, variables, arithmetic operators, comparison operators, logical operators, assignment operators, conditionals, ternary expressions, switch statements, loops, break and continue, functions, collections, and practice
- **Run locally:** `npm install` then `npm run dev`
- **Build:** `npm run build`
